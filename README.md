# nonamecoders.github.io

김영민의 이력서 페이지입니다. → https://nonamecoders.github.io/

## 내용 수정

이력서 내용은 모두 `_config.yml`에 있습니다. `main`에 푸시하면 GitHub Pages가 자동으로 다시 배포합니다.

## 로컬 실행

```bash
bundle install
bundle exec jekyll serve
# 또는
docker compose up
```

http://localhost:4000 에서 확인할 수 있습니다.
